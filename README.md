## Как пользоваться пакетом

1. Пройдите [чек-лист](01-checklist-audit-152fz.md) — отметьте «да / нет / частично».
2. По пунктам «нет» и «частично» сформируйте план устранения.
3. Заполните и утвердите недостающие документы из разделов 02–05.
4. Адаптируйте шаблоны под свою организацию (цели обработки, категории субъектов, ИСПДн).
5. Ознакомьте работников под подпись.
6. Разместите Политику на сайте.

## Дополнительно рекомендуется

- Уведомление Роскомнадзора + актуальная выписка из реестра операторов
- Акт определения уровня защищённости ИСПДн (по ПП РФ № 1119)
- Договоры с подрядчиками с условиями поручения обработки ПДн
- Подтверждение размещения баз данных на территории РФ
- При наличии биометрии / специальных категорий — отдельные согласия и меры защиты

> **Важно:** Документы носят справочный характер и не заменяют консультацию юриста или специалиста по защите информации. Состав мер зависит от специфики деятельности, категорий и объёма обрабатываемых данных.

## Ответственность

Нарушения 152-ФЗ квалифицируются по ст. 13.11 КоАП РФ. Штрафы по отдельным составам достигают сотен тысяч / миллионов рублей, при повторных нарушениях — существенно выше. Роскомнадзор проводит внеплановые проверки.
